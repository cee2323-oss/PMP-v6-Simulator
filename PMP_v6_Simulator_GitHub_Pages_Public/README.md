# PMP Training v6.0 Simulator

Public simulator shell for independently authored PMP practice content.

## Privacy / content control

The controlled 600-item draft question bank is **not stored in this public repository**. The simulator starts with a small DEMO dataset. Authorized testers can import the controlled JSON or CSV bank in **Settings → Import & Diagnostics**; imported data is stored in that browser's local storage.

## Important status

Practice content is independently authored and is not affiliated with or endorsed by PMI. Draft items are not represented as independently SME-validated or psychometrically calibrated until those external gates are actually completed.

## GitHub Pages

Publish from the `main` branch and repository root. The app is a static PWA and requires no build step.
