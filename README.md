# PMP Training v6.0 Simulator

Browser-based PMP Training v6.0 simulator shell for practice and simulation.

This public repository intentionally contains only the simulator code and DEMO data. The controlled 600-item draft bank remains private and is imported at runtime through the simulator.

Practice content is independently authored and is not affiliated with or endorsed by PMI. Draft items are not independently SME-validated or psychometrically calibrated.
